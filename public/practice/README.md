# 練習の素材（ハブ A-03 G11）

田の字型・間取りの練習に使う、架空の住戸計画案です（13 型 × A・B・C の 39 案）。

- 出典: 本プロジェクトの間取り収集セッションが 2026-11-04 に新規作成。用途は練習のみ。
- 第三者の図面のトレースは含みません。実在の図面とは照合していません。
- 2K〜4DK の一部は、2LDK〜4LDK の骨格を流用しています（収集セッションの報告による）。
- 寸法・構造・設備は計画上の仮定で、法規の適合や実施設計の確認は済んでいません。
- JSON は収集セッションの形のままです（envelope・rooms・doors・windows・fixtures・columns）。練習の画面が planCase の変換で読みます。
- 正解の線は、部屋の枠（rooms の x・y・w・h）から引きます。
- SVG は外形（0〜envelope.W、0〜envelope.D）の枠に切ってあります。1 px = 10 mm。
