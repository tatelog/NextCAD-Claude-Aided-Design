## 今回の開発範囲と理由（ハッカソン）

### 製品の範囲
- **江東区（13108）**を対象にします。PLATEAU の江東区データと、区の都市計画決定情報（用途地域）が、区単位で揃っているためです。
- P1 の地点は、利用者が地図か住所で指定します。地図は MapLibre で描き、傾けると建物（LOD1）が立体で見えます。周辺建物の3D（半径400m）も残しています。

### デモの範囲（検証用の表示範囲）
- **区役所（東京都江東区東陽4-11-28）から新砂・豊洲一帯**を、初期表示にします。2次メッシュ **533936・533946** の範囲です（約18.5km × 11.3km）。
- これは**デモを見せるための範囲**で、製品の境界ではありません。2次メッシュは、データの単位と合わないためです。
  - 道路（国土数値情報）は1次メッシュ単位で、展開すると約707MBです。
  - 筆（登記所備付地図）は区単位の zip で、変換は登記所のシート単位です。
  - 建物（PLATEAU）は3次メッシュ単位です。

### 今回は対象外にしたもの
- **郵便番号検索（スコープ外・MVP の判断）**: 入力欄は無効にしてあります。理由は次の2つです。
  - **API の申請が要る**: 日本郵便の公式「郵便番号・デジタルアドレス API」は、ゆうIDの登録、組織の登録、固定IPでのシステム登録（クライアントIDとシークレットの発行）が前提です。ハッカソン期間内に申請を完了できる見込みがないため、今回は外しました。
  - **OSS と両立しない**: 固定IPの中継サーバーは運営者ごとに必要で、OSS の本体には組み込めません。郵便番号データ（KEN_ALL）は、利用条件を確認できていません。
  - 将来は、利用者が郵便番号データを自分で取得して置く方式、または API の申請を済ませたうえでの追加を検討します。
- **住所検索（対象内）**: 国土地理院の住所検索 API を使います。利用条件は未確認で、画面にも表示しています。
- **筆界の法務上の確認**: 筆の位置は参考値です。
- **斜線・日影などの法規計算**: 条例の値は、画面と計算の対象外です（別の画面の範囲）。
- **iPad の実機での操作確認**: 未確認です。

## P1 の地図の作り（今回の変更）

- **変更の理由**: 検証ページで確かめた見た目と操作（道路の幅員の色、筆の選択、建物の立体表示）を、P1 でも同じに使えるようにするため。プロジェクトの技術スタック（MapLibre GL JS）とも揃えました。
- **以前**: 自前の描画（タイルを並べる方式）でした。
- **依存**: `maplibre-gl` を `6.15.0`（完全一致）で入れています。6.16.0 は公開から2週間未満だったため見送りました。
- **確認したこと**: 単体テスト（1859件）と型チェック、本番ビルドが通ります。開発サーバーのブラウザで、基図・道路・建物・筆の表示と、初期表示の筆 2-7 の選択を確認しました。
- **未確認**: iPad の指での操作（ピンチを含む）、本番環境での表示。
- **開発時の設定**: `vite.config.ts` で `maplibre-gl` を事前バンドルの対象から外しています（開発時に Worker が読めない問題を避けるため）。

## データの置き方（利用者が置く）

- 置く場所は `public/local-data/` です。このフォルダは `.gitignore` で除外していて、リポジトリには入りません。
- 置くファイル（無ければ、その層は「未取得」と表示します）:
  - `roads-koto.json`: 道路。`{ "roads": [{ "w": 幅員区分(1〜5), "c": 道路分類, "s": 状態, "g": [[経度, 緯度], ...] }] }`。元は国土数値情報（道路 N13、1次メッシュ単位）。
  - `koto-parcels.geojson`: 筆。登記所備付地図（江東区）を mojxml で GeoJSON にしたもの。プロパティに `地図名`、`筆ID`、`地番`、`大字名`、`丁目名`、`精度区分` を持つ。位置が付くのは公共座標系のシートだけです。
  - `buildings-koto.geojson.gz`: 建物（LOD1）。ポリゴンと、プロパティ `h`（高さ、m）を持つ GeoJSON。gzip でも、展開済みの JSON でもよい。元は PLATEAU の建物 GML（bldg:lod0RoofEdge と bldg:measuredHeight）。
- **準備スクリプトは未作成です**（作成予定）。今は、上の形式に合わせて手で作るか、別途変換してください。
